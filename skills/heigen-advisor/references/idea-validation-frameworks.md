# 创意与商业模式验证框架

将这些框架作为针对创业者项目的工作表，而非通用讲义。每个框都要求具体事实。

## 1. 精益画布引导问题

| 模块 | 应收集的信息 | 引导问题 |
| --- | --- | --- |
| 问题 | 排序后的 1–3 个问题 | 谁遇到？何时发生？现在如何处理？ |
| 用户细分 | 早期采用者与滩头市场 | 不要说“所有人”；最先服务谁？ |
| 独特价值主张 | 一句清晰承诺 | 为什么是你，而不只是更便宜？ |
| 方案 | 从功能到结果 | 什么是验证承诺的最小 V1？ |
| 渠道 | 获得首批用户的路径 | 不投广告如何触达前 10 位？ |
| 收入 | 付费对象与价格逻辑 | 对方会为什么具体结果付费？ |
| 成本 | 固定与可变成本 | 哪一项错误会最难扩展？ |
| 指标 | 激活、留存、收入 | 什么结果会让你停止或转向？ |
| 不公平优势 | 难复制的能力 | 数据、网络、品牌、独家渠道还是速度？ |

## 2. 客户访谈规则

谈用户的过去行为，不要推销想法或问假设性购买意愿。

1. 请讲讲你最近一次遇到 [问题场景] 的经历。
2. 当时你采取了什么办法？哪些有效、哪些无效？
3. 这给你带来多少时间、金钱、压力或风险成本？
4. 谁参与了决策或替代方案？
5. 如果现实限制不变，理想结果会是什么？

避免：“你会买吗？”“这个想法好吗？”  
替代为承诺测试：试点报名、预订单、预约、介绍决策人或共享使用数据。

## 3. 市场规模规则

- 自上而下：从有来源的行业规模开始，按地区、用户和支付能力逐步筛选，并展示计算。
- 自下而上：潜在账户数 × 转化率 × ARPU（或销量 × 单价）。
- 标明每个输入来自访谈、试点、公开资料还是待验证假设。

## 4. 单位经济检查表

- 定价与折扣；
- 单位成本及其包含项；
- 毛利；
- 获客成本；
- 回本周期或 LTV（适用时）；
- 可变销售与服务成本后的贡献毛利。
