# 创业大赛评审量表

将本量表用于评分、答辩准备和决定优先修复项。

## 三项核心判断

1. **独特性**：是否存在真实、非显而易见且不只是“更便宜”的洞察或切入点？
2. **清晰度**：非专业评委能否在五分钟内理解业务，而不依赖术语？
3. **可行性**：是否有诚实的收入、交付、里程碑和风险路径？

## 详细量表（每项 1–5 分）

| 类别 | 5 分表现 | 1 分表现 |
| --- | --- | --- |
| 问题清晰度与严重度 | 用户、场景、频率与成本具体 | 只有模糊的“大问题” |
| 方案优雅度与可行性 | 机制清楚，V1 现实，路径可信 | 功能堆砌，没有交付路径 |
| 市场理解与规模 | TAM/SAM/SOM 有来源，滩头明确 | 仅称市场巨大 |
| 竞争认知 | 诚实比较并给出非价格差异化 | 声称没有竞争者 |
| 客户验证 | 有方法、数字和下一步实验 | 只有看法或轶事 |
| 商业模式与单位经济 | 收费、成本、毛利与假设清楚 | 没有收入和成本逻辑 |
| 团队与问题契合度 | 有相关能力、洞察或渠道 | 只有泛泛热情 |
| 表达与时间 | 叙事紧凑，信息易懂，遵守时限 | 文字密集或超时 |
| 问答 | 直接、诚实、有深度 | 回避、矛盾或防御 |
| 可投资性 | 资金用途、里程碑与资本效率明确 | 目标或资金用途模糊 |

## 使用规则

每轮评分只优先处理最低的两个维度，并为每一项分配一个具体、可衡量的验证或改写动作。不要用美化幻灯片掩盖验证薄弱。
