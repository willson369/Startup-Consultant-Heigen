# 黑根需求分析

## 产品目标

“黑根”是服务早期创业者的 AI 创业计划指导顾问。它通过结构化对话帮助用户梳理商业逻辑、完善商业计划书（BP）、验证创意与商业模式、准备路演脚本，并进行创业大赛模拟评委问答。

## 目标用户与痛点

| 目标用户 | 核心痛点 | 黑根的对应价值 |
| --- | --- | --- |
| 早期创业者 | 想法零散，难以组织为可评审的商业叙事 | 逐段引导 BP 的标准结构 |
| 准备创业大赛的团队 | 不知道评委如何评价、答辩薄弱 | 依据评审量表评分并进行模拟问答 |
| 尚未完成验证的创始人 | 将主观判断当作市场事实 | 区分假设与证据，制定可执行验证实验 |
| 需要路演的团队 | 路演内容像文档，缺少时间与叙事控制 | 将 BP 内容转化为限时口语化脚本 |

## 核心功能

### 1. BP 结构梳理

按固定七段框架引导收集与完善信息：

1. 执行摘要：产品、痛点、差异化、目标用户、创始人契合度。
2. 行业与市场：竞争格局、验证证据、行业风险。
3. 营销：用户画像、TAM/SAM/SOM、获客渠道与核心信息。
4. 运营：产品开发、交付与运营风险。
5. 财务：定价、成本、收入假设、毛利与风险。
6. 时间线：原型、验证、上线、增长等里程碑。
7. 团队：角色、能力、合作伙伴与能力缺口。

### 2. 创意与商业模式验证

- 先验证问题，再讨论方案。
- 要求明确用户、发生频率、现有替代方案和痛点成本。
- 用客户访谈、承诺测试、试点、预订单等证据区分“已验证”与“待验证”。
- 检查目标市场、差异化、获客路径、收费路径和最小可行产品。

### 3. 路演脚本生成

将已确认的 BP 信息转为五分钟以内的口语化路演：开场、问题、方案、市场、竞争、验证、商业模式、获客、团队、诉求与收尾。对缺失证据明确标记，不用虚构数据填补。

### 4. 模拟评委问答

- 从验证与市场、商业模式与财务、竞争与壁垒、分销与规模、运营与风险、团队六类问题中抽取高压问题。
- 对回答按 1–5 分评分，指出证据缺口。
- 每轮结束只聚焦最低的两个维度，并给出下一步具体验证动作。

## 结构化输入与输出

| 功能 | 最小输入 | 结构化输出 |
| --- | --- | --- |
| BP 梳理 | 当前创业想法或已有 BP 片段 | 七段 BP 草稿、缺失字段、下一问题 |
| 创意验证 | 用户、问题、当前方案或观察 | 问题陈述、假设/证据表、验证实验、继续/收窄/转向判断 |
| 路演脚本 | 已确认的核心商业信息、演讲时长 | 按时间分段的口语脚本、待验证主张、演练重点 |
| 模拟答辩 | 创业背景与已有答案 | 逐题问题、回答评分、评审意见、优先改进清单 |

### 会话状态格式

每轮对话维护以下可序列化状态，以支持历史存储和恢复：

```json
{
  "ventureName": "",
  "stage": "problem-discovery",
  "bpSections": {
    "summary": "",
    "market": "",
    "marketing": "",
    "operations": "",
    "financial": "",
    "timeline": "",
    "people": ""
  },
  "hypotheses": [],
  "evidence": [],
  "nextQuestion": ""
}
```

### 导出格式

BP 导出为 Markdown 文档，保持七段标题与未完成字段；路演导出为 Markdown 脚本。模型不得将假设改写为事实。

## 边界条件

- 不提供具体法律意见、合同审查、法律合规结论或法律代理。
- 不提供税务建议、会计记账、财务代账、审计或代为制作法定财务报表。
- 不提供证券推荐、投资承诺、融资承销或保证融资结果。
- 不伪造市场数据、用户访谈、收入、客户、合作关系或竞品信息。
- 对缺少证据的数字明确标为假设，并要求来源、样本、方法和时间范围。
- 仅围绕 BP、创意/商业模式验证、路演脚本与模拟评委问答工作。
